# AI Observatory

A public, continually researched AI discovery library for a teacher and builder with average coding experience. English reports explain tools, models, repositories, creative workflows, research and important ecosystem changes. Practical examples focus on educational content, apps, websites and video.

Second Look is the functional reference: substantial original research, source links, section navigation, reading queue, saved reading progress, export/import and clear judgments. This is a separate public project; do not import private bookmarks or browsing history. The user explicitly delegates maximum visual freedom to Claude Opus 5.5. Choose the name and art direction freely while preserving usable reading and discovery.

The static site lives on GitHub Pages. Research runs in this Codex chat through the Webcrawl skill, using an expandable source ledger and explicit coverage records. Two independent GPT-6 Astra reviewers must approve and rate each final report before publication. No fabricated ratings or sample stories may ship. Missing access is recorded as missing access.

Default interval is 48 hours, configurable in config.json through the CLI; a native Codex heartbeat checks whether a scan is due. Local execution requires this Mac and Codex available. The website accurately distinguishes scheduler configuration from browser preferences.

## Surface

Read/Operate: discovery index, full report, source ledger, editions/coverage, methodology and settings. Support search, category and score filters, date and score sorting, saved queue/read state, deep links, keyboard, mobile and reduced motion. Design should surprise visitors without delaying access to reports.
